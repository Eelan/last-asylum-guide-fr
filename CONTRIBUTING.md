# Contribuer

Merci de vouloir améliorer le guide.

## Principes

- Rédiger en français clair.
- Ne pas recopier un guide tiers.
- Citer les sources externes utiles.
- Distinguer un fait observé d'une recommandation.
- Indiquer lorsqu'une information dépend d'une saison, d'un serveur ou d'une mise à jour.
- Ajouter des captures d'écran uniquement si vous avez le droit de les publier.

## Workflow conseillé

1. Créer une branche `guide/nom-du-sujet`.
2. Modifier ou créer le fichier Markdown.
3. Vérifier le rendu avec `mkdocs serve`.
4. Ouvrir une Pull Request.
