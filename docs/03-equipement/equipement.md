# Équipement

<div class="guide-meta"><span>⚔️ Équipement</span><span>💡 Optimisation</span></div>

## Principe général

Évitez d'améliorer chaque pièce simplement parce qu'elle est disponible. Concentrez vos matériaux sur les héros réellement utilisés.

## Questions utiles

- Ce héros restera-t-il dans mon équipe principale ?
- Cette amélioration renforce-t-elle sa fonction principale ?
- Ce matériau est-il requis pour un futur palier plus important ?
- Un événement récompense-t-il cette amélioration maintenant ?

## Documenter les pièces

Une future table indiquera pour chaque type de pièce : statistiques, coûts, paliers, matériaux et héros qui en profitent le plus.
