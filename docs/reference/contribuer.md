# Contribuer à un guide

## Modèle Markdown

Copiez ce modèle pour créer une nouvelle page :

```markdown
# Titre du guide

<div class="guide-meta"><span>🎯 Niveau</span><span>🆓 F2P</span><span>📝 Mise à jour</span></div>

## TL;DR

- Point essentiel 1
- Point essentiel 2
- Point essentiel 3

## Présentation

Expliquez la mécanique.

## Fonctionnement

Décrivez les règles vérifiées.

## Stratégie F2P

Indiquez les priorités sans achat.

## Si vous dépensez occasionnellement

Comparez les achats uniquement lorsqu'ils ont un intérêt réel.

## Erreurs à éviter

!!! warning
    Décrivez ici une erreur fréquente.

## À confirmer

Listez clairement les informations encore incertaines.

## Sources

- Observation en jeu — date
- Source externe éventuelle
```

## Statuts recommandés

- ✅ **Vérifié en jeu**
- 🧪 **Testé par la communauté**
- 💡 **Recommandation**
- ⚠️ **À confirmer**
- 🆓 **F2P**
- 💰 **Payant**

## Captures d'écran

Placez les images dans `docs/assets/images/` en utilisant des noms explicites et légers. Exemple :

```text
assets/images/duel-alliance/jour-1-objectifs.webp
```
