## Comment lire ce guide ?

!!! info "Un guide vivant"
    *Last Asylum: Plague* évolue. Certains chiffres, récompenses ou mécaniques peuvent varier selon les mises à jour et les serveurs. Chaque page doit indiquer clairement ce qui est confirmé, testé ou encore incertain.

### Notre priorité : l'efficacité

Le but n'est pas d'obtenir « le compte parfait », mais de répondre rapidement à des questions concrètes :

- **Qu'est-ce que je dois améliorer maintenant ?**
- **Quelles ressources dois-je conserver ?**
- **Quand dois-je utiliser mes accélérateurs ?**
- **Dans quels héros et équipements investir ?**
- **Que dois-je préparer pour mon alliance ?**
